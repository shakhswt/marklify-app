## 2024-03-24 - SimpleDateFormat in Compose Lazy Lists
**Learning:** `SimpleDateFormat` is expensive to instantiate, especially inside of Compose `LazyColumn` or `LazyRow` items blocks. While `remember` scopes it to the composition, as the list scrolls, new items are composed and new `SimpleDateFormat` instances are created for every element entering the viewport. This causes unnecessary object allocation and can hurt scrolling performance.
**Action:** Extract `SimpleDateFormat` out of Composable functions if it doesn't depend on Composable state, preferably to a private file-level variable, to ensure it is created exactly once and reused across all list items during scrolling. Note that `SimpleDateFormat` is not thread-safe, but since it is only accessed on the main UI thread during Compose rendering, a file-level private value is safe for this specific use case.
